## Звідки взялася програма

Ви залишили комп’ютер на ніч із відкритою роботою. Уранці на екрані — вхід до системи: Windows перезавантажила його о 01:30 заради драйвера відеокарти. У параметрах Windows про це ані слова, у «Переглядачі подій» тисячі записів, і заздалегідь ніхто не попередив.

RebootWhy відповідає на обидва запитання:

* **Після:** *що* перезавантажило комп’ютер, *хто* цього попросив і *чому* — з подіями журналу як доказом.
* **До:** чи чекає Windows Update на перезавантаження, *коли* воно може статися і *чому Windows вважає, що можна не питати*. І гучно попереджає, поки ще є час зберегти роботу.

## Можливості

### Історія перезавантажень із причинами

* Час роботи, останнє повне завантаження й активний час без сну. Швидкий запуск і глибокий сон враховуються: «Завершення роботи» зі швидким запуском не перезапускає ядро.
* Для кожного завантаження за вибраний період — причина простими словами:
  * **Windows Update** (сам або за вашою командою зі сповіщення) і список оновлень, установлених перед перезавантаженням;
  * **ви** — з меню «Пуск» або кнопкою живлення;
  * **команда** (`shutdown.exe`), **інсталятор** або **програма** — зі шляхом процесу, користувачем і кодом причини;
  * **синій екран** — назва помилки, пояснення та шлях до дампу пам’яті;
  * **зникнення живлення / зависання / кнопка Reset**, **утримання кнопки живлення**, **збій сну**, **вихід із глибокого сну**;
  * апаратні помилки (WHEA) поруч зі збоєм.
* Рівень упевненості та **події журналу, на яких ґрунтується висновок**: усе можна перевірити самостійно.
* Можна відкрити `.evtx`-журнал **з іншого комп’ютера**.
* Одна кнопка копіює пояснення повністю — для форуму чи звернення до підтримки.

### Стеження за Windows Update і попередження заздалегідь

* Читає журнали **Update Orchestrator** — компонента Windows, який насправді вирішує, коли перезавантажувати, — і знаходить установлені оновлення, що чекають на перезавантаження.
* Обчислює, **коли** перезавантаження можливе: кінець активних годин і найближчий запуск завдань `Schedule Work` / `Schedule Wake To Work`.
* Пояснює, **чому** Windows може перезавантажити без запитання: «оновлення вважається схваленим вами раніше», «прострочене», «відкладено, поки ви за комп’ютером».
* Попереджає так, як ви налаштуєте: сповіщення Windows, **вікно поверх усіх** (одразу після виявлення й ще раз за N хвилин), **власний звук** (mp3, wav, ogg) і **«Нагадати через…»**.
* **Тримає комп’ютер «зайнятим»**, поки Windows чекає на перезавантаження: за активного користувача Windows відкладає автоматичне перезавантаження. Ручне перезавантаження це не блокує.
* Значок у треї **червоніє**, коли Windows чекає на перезавантаження.
* **Перевірка реакції:** імітує оновлення з перезавантаженням через 3 хвилини, щоб перевірити сповіщення. У Windows нічого не змінюється, справжнього перезавантаження не буде.

### Вкладка «Оновлення»

* Увесь **журнал установлення**: дата, результат, код помилки з розшифровкою, хто запустив, стаття KB, посилання.
* **Оновлення, про які Windows уже знає, але ще не встановила.** Рядки підсвічені **червоним**, якщо перезавантаження знадобиться, і **помаранчевим**, якщо може знадобитися.
* Миттєвий пошук за назвою, номером KB та описом, фільтри за типом і потребою в перезавантаженні.

### Політики Windows Update в одному місці

З правами адміністратора:

* **Не перезавантажувати автоматично, коли користувач увійшов** (`NoAutoRebootWithLoggedOnUsers`);
* **Не отримувати драйвери разом з оновленнями Windows** (`ExcludeWUDriversInQualityUpdate`);
* **Режим автоматичного оновлення** (сповіщати / завантажувати / встановлювати за розкладом).

### Служба (необов’язково)

Програма працює й без неї. Служба, яку можна встановити з налаштувань, додає:

* **точний** розклад завдань Windows Update з Планувальника — його бачить лише адміністратор;
* стеження, навіть коли програму не запущено;
* миттєву доставку змін до програми через локальний іменований канал.

## Сильні сторони

| | |
|---|---|
| **Пояснює, а не перелічує** | Інші утиліти показують час завантаження. RebootWhy називає причину й показує докази. |
| **Попереджає до того, як** | Читає ті самі журнали Update Orchestrator, за якими Windows планує перезавантаження, — ви дізнаєтеся раніше, ніж утратите роботу. |
| **Будь-яка мова Windows** | Аналіз спирається на коди й поля подій, а не на тексти повідомлень. |
| **Приватно** | Жодної мережі, телеметрії чи облікових записів. Усе читається з локальних журналів. |
| **Легка й портативна** | Один `.exe` з усім необхідним: без інсталятора, без установлення .NET, без прав адміністратора для основних функцій. |
| **Безпечно** | Програма лише читає. Змінює вона тільки політики Windows Update, які ви перемкнете самі, і необов’язкову службу. |
| **Відкритий код, MIT** | Перевірена на синтетичних журналах і на справжніх журналах Update Orchestrator того самого нічного перезавантаження. |

## Завантажити й запустити

1. Завантажте `RebootWhy.exe` зі [сторінки останнього випуску](../../releases/latest).
2. Запустіть. Нічого встановлювати не потрібно, .NET уже всередині.
   *SmartScreen може попередити про невідомого видавця: exe не підписано. Натисніть «Докладніше → Усе одно запустити» або [зберіть програму самі](docs/BUILDING.md).*
3. За бажанням: у **Налаштуваннях** увімкніть запуск разом із Windows, установіть службу та виберіть способи попередження.

Вимоги: Windows 10 або 11, x64. Розробляється й перевіряється на Windows 11. Мову інтерфейсу — англійську, російську, українську чи вірменську — можна вибрати в налаштуваннях.

## Запитання й відповіді

**RebootWhy заборонить Windows перезавантажуватися?**
Значно знизить імовірність: попередить заздалегідь, може тримати сеанс «зайнятим», поки Windows чекає на перезавантаження, і дає змогу ввімкнути політику «не перезавантажувати, коли користувач увійшов». Але в деяких випадках Windows Update усе ж може перезавантажити комп’ютер — для цього й потрібне попередження.

**Чи можна перезавантажитися вручну?**
Так. Перезавантаження з меню «Пуск», кнопкою живлення чи `shutdown.exe` працює як завжди.

**Чи потрібні права адміністратора?**
Для історії, списку оновлень і попереджень — ні. Вони потрібні лише для встановлення служби та зміни політик Windows Update; Windows попросить їх сама (UAC).

**Програма щось надсилає?**
Ні. RebootWhy не користується мережею. Навіть список відомих оновлень береться з локальної бази Windows Update, без звернення до серверів Microsoft.

**Як розібрати перезавантаження іншого комп’ютера?**
На ньому виконайте `wevtutil epl System C:\logs\System.evtx`, перенесіть файл і відкрийте його в RebootWhy.
